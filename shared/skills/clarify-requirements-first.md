# Clarify Requirements First
## Purpose
Prevent wrong implementations caused by ambiguity.

## Workflow
1. Restate requested outcome.
2. Identify missing constraints.
3. Identify assumptions.
4. Ask only high-value questions.
5. Propose default assumptions if user prefers speed.

## Ask About
- success criteria
- scope boundaries
- compatibility constraints
- deadlines
- risk tolerance

## Anti-patterns
- coding immediately
- asking 20 trivial questions
- pretending certainty
